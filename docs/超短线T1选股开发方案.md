# 超短线 T+1 选股开发方案（v2 — 多策略框架）

## 业务场景

**今日买入，明日卖出。** T 日收盘后选股 → T+1 日开盘买入 → T+2 日开盘无条件卖出。无论盈亏都离场，有效防范被套风险。

## 当前积分：2120 数据能力总览

| Tushare 接口 | 积分 | 状态 | 提供的数据 |
|-------------|------|------|-----------|
| `daily` | 120 | 可用 | 日线 OHLCV：open/high/low/close/pre_close/vol/amount |
| `moneyflow` | 2000 | 可用 | 个股主力净流入（net_mf_amount） |
| `stk_limit` | 2000 | 可用 | 每日涨跌停价格 |
| `kpl_list` | 2000+ | 可用 | 涨停板榜单：涨停时间/封单额/连板/炸板/题材 |
| `top_list` | 2000 | 可用 | 龙虎榜每日明细：买入额/卖出额/净买额/上榜原因 |
| `top_inst` | 2000 | 可用 | 龙虎榜机构席位交易明细 |
| `moneyflow_dc` | 5000 | 不可用 | 精细资金流（超大单/大单分类） |
| `stk_auction` | 分钟 | 不可用 | 集合竞价量价 |
| `stk_mins` | 分钟 | 不可用 | 分钟K线 |

**核心认知：** 日线 OHLCV 数据（120积分即可）已经包含 open/high/low/close/volume，足以支撑大量技术分析策略。`kpl_list` 和 `top_list` 是增量，不是基础。

---

## 一、策略体系总览

T+1 选股不是单一策略，而是多策略并行、各自独立评分、最后统一融合的框架。

```
T日 15:30 收盘
  │
  ├─ 策略A：超跌反弹 ────→ 候选池A + 评分A
  ├─ 策略B：缩量止跌 ────→ 候选池B + 评分B
  ├─ 策略C：资金背离 ────→ 候选池C + 评分C
  ├─ 策略D：均线支撑 ────→ 候选池D + 评分D
  ├─ 策略E：阳包阴 ────→ 候选池E + 评分E
  ├─ 策略F：涨停板次日 ──→ 候选池F + 评分F
  ├─ 策略G：强势回踩 ────→ 候选池G + 评分G
  │
  ├─ 统一评分归一化（策略内百分制 → 跨策略可比）
  ├─ 去重 + 分散化（同板块/同策略上限）
  ├─ 风控过滤（流动性/波动率/基本面）
  │
  └─ 输出 Top 3-5 标的
```

每个策略回答三个问题：
1. **什么股票能进候选池？**（准入条件，硬门槛）
2. **进了候选池后怎么打分？**（评分公式，软排序）
3. **什么市场环境该策略有效？**（环境适配，开关控制）

## 二、七大策略详细设计

### 策略 A：超跌反弹（Oversold Bounce）

**场景：** 连续多日下跌，卖盘力量衰竭，技术性反弹概率升高。俗称"连跌抄底"。

**数据依赖：** `daily` OHLCV（已有，无需新接口）

**准入条件（全部满足才进候选池）：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 连续下跌天数 | >= 3天（每日 close < pre_close） | 足够的超卖积累 |
| 近3日累计跌幅 | -4% ~ -15% | 跌太少反弹力不足，跌太多可能是崩盘 |
| 量比 | < 0.6（当日量 / 近20日均量） | 缩量下跌 = 卖盘衰竭而非恐慌出逃 |
| 当日跌幅 | > -7%（非跌停） | 跌停可能次日惯性低开 |
| 非 ST | 排除 ST/*ST | 涨跌幅限制不同 |
| 流通市值 | > 30亿 | 流动性保障 |

**评分公式（0-100）：**

```
连跌天数分：
  3天 → +15   4天 → +25   5天 → +20   6天 → +10   >=7天 → +5

缩量分：
  量比 < 0.3 → +30   量比 < 0.5 → +20   量比 < 0.7 → +10

影线反转分（下影线 = (min(open,close) - low) / (high - low)）：
  下影线 > 上影线*2 且 当日收阳 → +20
  下影线 > 上影线*2 且 当日收阴 → +10

偏离度分（close 距 MA20）：
  < -8% → +25    < -5% → +20    < -3% → +15    < -1% → +10

跌幅质量分（近3日累计）：
  -6% ~ -10% → +20（温和超卖最优）
  -4% ~ -6%  → +15
  -10% ~ -15% → +10（较深但可接受）

当日信号分：
  收阳线（close > open）→ +10
```

**市场环境适配：**
- 最佳：ROTATION（轮动市中超跌反弹最有效）
- 可用：UPTREND、EVENT_DRIVEN
- 关闭：RISK_OFF（恐慌市抄底危险）、DEFENSIVE（防御市可能阴跌不止）

---

### 策略 B：缩量止跌（Volume Exhaustion）

**场景：** 长期低迷、成交萎靡到极致，卖方已经不想卖了。地量见地价，稍有买盘就能推动反弹。这就是你提到的"连续多日持续低迷"的典型场景。

**数据依赖：** `daily` OHLCV（已有）

**准入条件：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 近5日累计涨跌幅 | -3% ~ +1% | 已经不跌了，价格企稳 |
| 当日成交量 | = 近20日最低 | 极端缩量，卖盘枯竭 |
| 量比 | < 0.5 | 确认缩量程度 |
| 前10日内 | 出现过连续 >= 2日下跌 | 确认经历过调整而非一直横盘 |
| 流通市值 | > 50亿 | 大盘股缩量止跌更可靠 |
| 非 ST | 排除 | 常规过滤 |

**评分公式（0-100）：**

```
缩量极值分：
  20日最低 → +30   5日最低 → +15   3日最低 → +10

K线形态分：
  十字星（abs(open-close)/close < 0.003）→ +20
  小阳线（close>open 且 涨幅<1%）→ +15
  小阴线（close<open 且 跌幅<1%）→ +5

均线位置分：
  距MA20在 ±1% → +15（均线附近止跌 = 支撑确认）
  距MA20在 ±2% → +10

连续缩量天数分：
  >= 3日量比持续<0.6 → +10

资金确认分（需要 moneyflow 数据）：
  主力净流入 > 0 → +20
  主力净流入 > 1000万 → +10 额外

PE 辅助分：
  PE > 0 且 PE < 40 → +5（估值合理，不是在杀估值）
```

**市场环境适配：**
- 最佳：DEFENSIVE、ROTATION（防御和轮动市中缩量止跌最可靠）
- 可用：UPTREND
- 关闭：RISK_OFF

**特别说明：** 这个策略在 DEFENSIVE 环境反而有效，因为它找的是"跌不动"的股票，不依赖上涨动能。

---

### 策略 C：资金背离（Capital Divergence）

**场景：** 股价在跌，但主力资金在持续净流入——"价跌量增、资金逆向"。这是主力悄悄吸筹的经典信号。

**数据依赖：** `daily` OHLCV + `moneyflow`

**准入条件：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 当日主力净流入 | > 0 | 资金在进 |
| 当日涨跌幅 | < 0（股价在跌） | 背离必须价跌资金进 |
| 近3日背离天数 | >= 2日（至少有2天"价跌资金进"） | 确认背离不是偶然 |
| 近5日累计跌幅 | < 10% | 不是崩盘式下跌 |
| 量比 | > 0.5 | 有一定量能支撑，不是完全没交易 |
| 流通市值 | > 30亿 | 流动性保障 |

**评分公式（0-100）：**

```
背离持续性分：
  连续3日价跌资金进 → +30
  近3日有2日背离 → +20
  仅当日背离 → +10

净流入规模分：
  净流入 > 5000万 → +30
  净流入 > 2000万 → +20
  净流入 > 500万 → +10

资金占比分（净流入 / 当日成交额）：
  > 15% → +20    > 8% → +15    > 3% → +10

跌幅质量分：
  当日跌幅 -0.5% ~ -3% → +15（温和下跌+资金进最理想）
  当日跌幅 -3% ~ -5% → +10

龙虎榜加持分（需 top_list 数据）：
  on_top_list 且 net_amount > 0 → +15
```

**市场环境适配：**
- 最佳：ROTATION、DEFENSIVE
- 可用：UPTREND
- 关闭：RISK_OFF

**风险提示：** 资金流向数据来自东方财富模型（通过挂单大小分类），不是真实的机构交易数据，有一定噪声。背离信号需要叠加其他策略确认。

### 策略 D：均线支撑（MA Support Bounce）

**场景：** 上升趋势中的股票正常回调到 MA20，触碰均线后反弹。属于"牛回头"中最温和的一种——不是在追高，而是在趋势中途的低点介入。

**数据依赖：** `daily` OHLCV（已有）

**准入条件：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 近10日趋势 | trend_strength > 0（MA5 > MA20） | 之前处于上升趋势 |
| 距MA20偏离 | -1% ~ +1%（收盘价紧贴MA20） | 刚好回踩到均线 |
| 近3日累计跌幅 | -2% ~ -8% | 确实在回调中 |
| 量比 | < 0.8 | 缩量回调 = 良性调整 |
| 当日跌幅 | > -5% | 不是大阴线砸穿均线 |
| 非 ST | 排除 | 常规过滤 |

**评分公式（0-100）：**

```
趋势质量分：
  trend_strength > 5% → +25（强趋势回踩最可靠）
  trend_strength > 2% → +20
  trend_strength > 0  → +15

缩量分：
  量比 < 0.4 → +20   量比 < 0.6 → +15   量比 < 0.8 → +10

影线确认分：
  下影线 > 实体长度*2 → +15（盘中触均线后被拉起）

均线排列分：
  MA5 > MA20 > MA60 → +15（多头排列更可靠）
  MA5 > MA20 但 MA20 < MA60 → +5

PE 分：
  PE > 0 且 PE < 40 → +10

资金分（可选）：
  主力净流入 > 0 → +10
```

**市场环境适配：**
- 最佳：UPTREND（上升趋势中均线支撑最有效）
- 可用：ROTATION
- 关闭：RISK_OFF（跌势中均线是压力而非支撑）

### 策略 E：阳包阴（Bullish Engulfing）

**场景：** 经典的 K 线反转形态。前一日收阴线，今日低开后高走，收盘价完全吞没前一日阴线实体。放量阳包阴是教科书级别的短线反转信号。

**数据依赖：** `daily` OHLCV（已有）

**准入条件：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 前一日 | close < open（阴线） | 确认前日是卖盘主导 |
| 当日 | close > open（阳线） | 当日转为买盘主导 |
| 当日开盘 | open < 前日 close（低开） | 开盘延续悲观，但被逆转 |
| 当日收盘 | close > 前日 open（完全吞没） | 阳线实体覆盖了阴线实体 |
| 量比 | > 1.2（放量） | 放量确认反转有效 |
| 非 ST | 排除 | 常规过滤 |

**评分公式（0-100）：**

```
吞没力度分（当日收盘超出前日开盘的幅度）：
  超出 > 2% → +25   超出 > 1% → +20   超出 > 0.5% → +15

量能确认分：
  量比 > 2.5 → +25   量比 > 1.8 → +20   量比 > 1.2 → +15

位置分（低位吞没更有意义）：
  距MA20 < -5% → +25（深度超卖区的吞没最有力）
  距MA20 < -2% → +20
  距MA20 < 0  → +10

前日阴线质量分：
  前日实体 > 2% → +15（吞没大阴线 > 吞没小阴线）

资金分：
  主力净流入 > 0 → +15

收盘强度分：
  收盘价接近当日最高价（(close-low)/(high-low) > 0.8）→ +10
```

**市场环境适配：**
- 最佳：ROTATION、EVENT_DRIVEN（震荡市中形态策略表现最好）
- 可用：UPTREND
- 关闭：RISK_OFF

### 策略 F：涨停板次日（Limit-Up Next Day）

**场景：** 涨停板是市场当天"投票选出的最强股"。但涨停股次日表现分化——早封板+高封单比的首板次日溢价概率高，尾盘偷鸡板/炸板回封的次日大概率低开。关键是筛选"好涨停"。

**数据依赖：** `daily` OHLCV + `kpl_list` + `top_list`

**准入条件：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 当日涨停 | 收盘价 = 涨停价 | 确认封死涨停 |
| 涨停时间 | 早于 10:30 | 早盘板强度 > 午后板 |
| 涨停类型 | 自然涨停（换手板） | 一字板次日无买入机会 |
| 未炸板 | open_time 为空 | 炸板过的封板质量打折 |
| 连板状态 | 首板或二板 | 三板以上风险急剧放大 |
| 封单比 | > 0.5%（封单额/流通市值） | 封单意愿强 |
| 流通市值 | 20亿 ~ 300亿 | 太小无流动性，太大难拉升 |
| 非 ST | 排除 | ST 涨跌幅 5% |

**评分公式（0-100）：**

```
涨停时间分（按当日全市场涨停时间排名）：
  排名前3 → +35    前10 → +25    前30 → +15    30名之后 → +5

封单比分：
  > 2% → +30    > 1% → +20    > 0.5% → +10    > 0.3% → +5

连板分：
  首板 → +15    二板 → +5    三板 → -10    四板+ → -25

题材分：
  当日涨停数量 >= 3 的同题材 → +15（板块效应确认）
  当日涨停数量 >= 2 的同题材 → +10

资金确认分：
  主力净流入 > 0 → +10
  龙虎榜 net_amount > 0 → +10

竞价分（来自 kpl_list）：
  bid_change > 0（竞价净买入） → +10
```

**市场环境适配：**
- 最佳：UPTREND、EVENT_DRIVEN
- 可用：ROTATION
- 关闭：DEFENSIVE（涨停股少且次日溢价低）、RISK_OFF

---

### 策略 G：强势回踩（Strong Stock Pullback）

**场景：** 近期涨幅强势的龙头股出现 2-3 天回调，但关键支撑（MA20）未破，是"牛回头"的介入机会。不同于策略D的温和回调——这里的标的近期有显著涨幅，是市场的关注焦点。

**数据依赖：** `daily` OHLCV（已有）

**准入条件：**

| 条件 | 阈值 | 原因 |
|------|------|------|
| 近20日涨幅 | > 8% | 前期足够强势 |
| 近3日累计跌幅 | -3% ~ -10% | 在回调而非崩盘 |
| 当日收盘 | > MA20 | 支撑有效，未跌破 |
| 量比 | < 0.7 | 缩量回调 = 洗盘而非出货 |
| 流通市值 | > 30亿 | 流动性保障 |
| 非 ST | 排除 | 常规过滤 |

**评分公式（0-100）：**

```
前期强度分：
  20日涨幅 > 25% → +25    > 15% → +20    > 10% → +15    > 8% → +10

缩量质量分：
  量比 < 0.3 → +20    < 0.5 → +15    < 0.7 → +10

当日企稳信号分：
  收阳线 → +15
  下影线 > 上影线*1.5 → +10

均线支撑分：
  距MA20 < 1%（精准回踩）→ +15
  距MA20 < 2% → +10

题材加持分：
  有 theme_tags → +10（龙头通常有题材属性）

资金分：
  主力净流入 > 2000万 → +15
  主力净流入 > 0 → +5

回调质量分（近3日）：
  每日跌幅都 < 3% → +10（温和回调）
  某日跌幅 > 5% → -5（有恐慌成分）
```

**市场环境适配：**
- 最佳：UPTREND（牛市中的龙头回调是黄金买点）
- 可用：ROTATION
- 关闭：DEFENSIVE、RISK_OFF

## 三、跨策略融合机制

### 3.1 评分归一化

各策略的评分尺度不同（涨停板策略可能普遍高分），需要在各自策略内部做百分位归一化：

```python
def normalize_strategy_scores(candidates, strategy_name):
    """策略内 min-max 归一化到 0-100"""
    if len(candidates) <= 1:
        for c in candidates:
            c.normalized_score = c.raw_score
        return
    scores = [c.raw_score for c in candidates]
    min_s, max_s = min(scores), max(scores)
    span = max_s - min_s
    for c in candidates:
        c.normalized_score = ((c.raw_score - min_s) / span * 100) if span > 0 else 50
```

### 3.2 策略权重分配

不同市场环境下，各策略的权重动态调整：

| 策略 | UPTREND | ROTATION | EVENT_DRIVEN | DEFENSIVE | RISK_OFF |
|------|---------|----------|-------------|-----------|----------|
| A 超跌反弹 | 15% | **25%** | 15% | 关闭 | 关闭 |
| B 缩量止跌 | 10% | 20% | 10% | **30%** | 关闭 |
| C 资金背离 | 10% | 20% | 15% | **25%** | 关闭 |
| D 均线支撑 | **25%** | 15% | 10% | 关闭 | 关闭 |
| E 阳包阴 | 10% | 15% | **20%** | 15% | 关闭 |
| F 涨停板次日 | **25%** | 10% | **25%** | 关闭 | 关闭 |
| G 强势回踩 | **20%** | 10% | 10% | 关闭 | 关闭 |

DEFENSIVE 下只保留 B（缩量止跌）+ C（资金背离）两个防御型策略。
RISK_OFF 下所有策略关闭，不推荐任何标的。

### 3.3 去重与分散化

同一只股票可能被多个策略选中（如一只下跌股同时满足超跌反弹+资金背离+阳包阴）。去重规则：
- 保留该股票所有策略评分中最高的那个
- 记录"多策略共振"标记，可作为加分项（+5分）

分散化约束（在 PortfolioGuard 中已有框架）：
- 同一策略类型最多输出 2 只
- 同一板块/题材最多输出 1 只
- 总输出 3-5 只

## 四、数据层改造

### 4.1 现有数据已满足大部分需求

核心数据表 `market_daily_bar_truth` 已有 open/high/low/close/volume/turnover，配合 `moneyflow`（net_mf_amount）和 `stock_daily_basic`（pe_ttm/pb/turnover_rate），策略 A/B/C/D/E/G 的所有特征都可以直接从这些表中计算，**不需要新建数据表**。

### 4.2 新增数据表（仅策略F需要）

```sql
-- 涨停板数据（kpl_list 接口，2000+ 积分）
CREATE TABLE stock_limit_up_daily (
    id VARCHAR(64) PRIMARY KEY,
    trade_date DATE NOT NULL,
    ts_code VARCHAR(32) NOT NULL,
```

### 4.4 特征计算函数

在 Go backend 的 `buildStockQuantScore` 旁边新增 `buildIntradayFeatures`：

```go
func buildIntradayFeatures(symbol string, quotes []stockQuoteCandle, 
    moneyflow *stockMoneyflowPoint, limitUp *stockLimitUpRecord, 
    topList *stockTopListRecord) model.IntradayFeatures {
    
    lastIdx := len(quotes) - 1
    latest := quotes[lastIdx]
    prev := quotes[lastIdx-1]
    
    // 短周期动量
    m1 := (latest.ClosePrice/latest.PrevClosePrice - 1) * 100
    
    var m2, m3 float64
    if lastIdx >= 2 && quotes[lastIdx-2].ClosePrice > 0 {
        m2 = (latest.ClosePrice/quotes[lastIdx-2].ClosePrice - 1) * 100
    }
    if lastIdx >= 3 && quotes[lastIdx-3].ClosePrice > 0 {
        m3 = (latest.ClosePrice/quotes[lastIdx-3].ClosePrice - 1) * 100
    }
    
    // 连续下跌天数
    consecutiveDown := 0
    for i := lastIdx; i >= 0; i-- {
        if quotes[i].ClosePrice < quotes[i].PrevClosePrice && quotes[i].PrevClosePrice > 0 {
            consecutiveDown++
        } else {
            break
        }
    }
    
    // K线形态
    bodyPct := math.Abs(latest.ClosePrice-latest.OpenPrice) / latest.ClosePrice
    lowerShadow := (math.Min(latest.OpenPrice, latest.ClosePrice) - latest.LowPrice) / 
                   math.Max(latest.HighPrice-latest.LowPrice, 0.01)
    upperShadow := (latest.HighPrice - math.Max(latest.OpenPrice, latest.ClosePrice)) / 
                   math.Max(latest.HighPrice-latest.LowPrice, 0.01)
    isDoji := bodyPct < 0.003
    
    // 阳包阴
    isEngulfing := latest.ClosePrice > latest.OpenPrice &&                    // 今日阳线
                   prev.ClosePrice < prev.OpenPrice &&                        // 前日阴线
                   latest.OpenPrice < prev.ClosePrice &&                       // 低开
                   latest.ClosePrice > prev.OpenPrice                          // 吞没
    
    // 均线偏离
    ma5 := calcMA(quotes, 5)
    ma10 := calcMA(quotes, 10)
    ma20 := calcMA(quotes, 20)
    ma60 := calcMA(quotes, 60)
    
    devMA5 := (latest.ClosePrice/ma5 - 1) * 100
    devMA10 := (latest.ClosePrice/ma10 - 1) * 100
    devMA20 := (latest.ClosePrice/ma20 - 1) * 100
    devMA60 := (latest.ClosePrice/ma60 - 1) * 100
    
    // 量在近20日排名
    volRank := calcVolumeRank(quotes, lastIdx, 20)
    volContractionDays := calcVolumeContractionDays(quotes, lastIdx)
    
    // ... 返回 IntradayFeatures 结构体
}
```

## 七、预期效果

| 指标 | 保守 | 乐观 | 说明 |
|------|------|------|------|
| 日均候选数（融合后） | 5-15 只 | 15-30 只 | 取决于当日市场环境 |
| hit_rate_1 | 54%-58% | 58%-63% | 多策略共振标的最优 |
| avg_return_1 | +0.3%-0.8% | +0.5%-1.5% | 含全部交易成本 |
| 策略覆盖率（交易日） | 70% | 85% | RISK_OFF 日关闭，其余运行 |
| 月胜率 | 55%-60% | 60%-68% | 月度正收益概率 |

**多策略的核心价值不在单一策略的准确率，而在于：**
1. 不同市场环境有不同的策略在生效，整体不会"空仓"
2. 多个策略同时选中的股票（共振标的）准确性显著更高
3. 分散化降低了单一策略失效的风险
4. 防御型策略（B/C）在弱势市场仍能选股

## 八、策略互斥关系与风控

| 风险场景 | 应对机制 |
|----------|---------|
| 某策略连续 N 日 hit_rate_1 < 45% | 自动降权或暂停该策略 |
| 全市场 RISK_OFF | 全部策略关闭，不推荐 |
| 同只股票被3+策略选中 | 标记为"高共振"，+5分但不重复计入 |
| 某板块出现集体跌停 | 该板块全部标的排除 |
| 单日推荐数不足3只 | 降低 min_score 阈值到 55，增加数量 |
| 策略A在单边下跌市中亏损 | DEFENSIVE 下降低 A 的权重至 0 |
