# 超短线 T+1 正式推荐设计规范

## Summary

本设计定义一套面向 `沪深主板` 的超短线 `T+1` 股票正式推荐系统，目标不是预测“盘中会不会拉一下”，而是提升：

- `按统一交易规则执行后最终盈利` 的概率
- 用户对推荐纪律、失效条件和复盘口径的信任
- 系统在弱市、强市和主线切换中的一致性表达

本阶段以“先做稳，再扩张”为原则，明确收口：

- 第一阶段只做 `沪深主板`
- 只做 `上市满 60 个交易日`、`近 20 日日均成交额 >= 5 亿` 的股票
- `T 日涨停股` 不进入次日正式推荐
- 风格采用 `双核混合，但默认偏强势回踩低吸`
- 正式推荐每天 `1-2` 只，弱市最多 `1` 只

## Product Contract

### 1. 结果口径

系统以 `真实可交易盈利` 作为核心结果口径，而不是盘中最大涨幅或收盘是否上涨。

第一阶段交易规则固定为：

- `T 日收盘` 生成观察池
- `T+1 09:30-10:00` 做开盘确认
- `T+1 10:00` 按当时可成交价视为买入
- `T+1 盘中` 只处理止损，不做提前止盈
- `T+2 开盘` 统一卖出

为保证回测与线上复盘口径一致，系统评估默认使用：

- `10:00-10:01` 成交均价作为参考买入价
- `T+2 开盘可成交价` 作为默认退出价

### 2. 输出结构

系统每日分两层输出：

- `观察池`
  提供当日继续跟踪的机会名单，承担信息覆盖职责
- `正式推荐`
  只输出最值得承担结果的 `1-2` 只股票，承担交易结论职责

第一阶段默认：

- 观察池规模 `8-15` 只
- 正常市正式推荐 `1-2` 只
- 弱市正式推荐最多 `1` 只

### 3. 市场状态

系统只区分两个市场状态：

- `NORMAL`
- `WEAK_RISK_OFF`

切换规则采用 `综合判定`：

- 指数与成交
- 短线情绪
- 主线持续性

上述三个维度中，至少 `2` 个同时转弱，系统从 `NORMAL` 切换到 `WEAK_RISK_OFF`。

### 4. 仓位纪律

第一阶段仓位采用“激进但保留缓冲”的固定规则：

- `NORMAL`
  - `1` 只正式推荐：总仓位 `80%`
  - `2` 只正式推荐：主票 `45%`，副票 `35%`
- `WEAK_RISK_OFF`
  - 最多 `1` 只正式推荐
  - 单票仓位 `40%`

### 5. 风险纪律

#### 止损

第一阶段采用 `组合止损`：

- `硬止损`
  相对参考买入价回撤达到 `-3%` 必须退出
- `结构止损`
  满足任一条件即可退出：
  - 跌破 `09:30-10:00` 的关键确认低点
  - `连续 5 分钟弱于 VWAP` 且未出现明显修复

#### 止盈

第一阶段 `不做提前止盈`。

设计取舍：

- 放弃盘中主观择时
- 强化规则一致性
- 允许盈利回吐作为策略代价

### 6. 追高边界

系统只允许在确认后追到相对昨收 `+4%` 以内。

若 `10:00` 时涨幅超过 `+4%`，即使其他信号较强，也不进入正式推荐。

## Universe Contract

第一阶段观察池准入采用强收口：

- 只做 `沪深主板`
- 排除 `ST/*ST`
- 排除停牌或明显流动性异常股票
- `上市天数 >= 60`
- `近 20 日日均成交额 >= 5 亿`
- `T 日不是涨停股`
- 排除明显一字板、公告风险显著、盘口异常标的

这一定义的目标不是捕捉全市场最大弹性，而是优先保证：

- 可交易性
- 规则一致性
- 解释与复盘质量

## Overnight Watchlist Model

`T 日收盘` 的预选模型输出的是“明早值得继续验证的观察假设”，不是最终交易指令。

### 1. 观察池结构

观察池分两类：

- `A 类：强势回踩修复型`
  主轴，约占 `60%-70%`
- `B 类：非涨停强势续航型`
  副轴，约占 `30%-40%`

### 2. A 类准入逻辑

关注以下条件：

- 过去 `10-15` 个交易日存在明确强势段
- 最近 `3-5` 个交易日为温和回调，不是破位下杀
- 回调过程最好缩量
- `T 日收盘` 存在修复或企稳迹象
- 所属板块未明显退潮

### 3. B 类准入逻辑

关注以下条件：

- 近 `5-10` 个交易日相对强度靠前
- `T 日` 强势但未涨停
- 收盘接近日内高位区域
- 成交和换手健康，不处于失控情绪顶点
- 距离短期均线不过远

### 4. 隔夜评分

隔夜观察池统一采用 `100` 分制：

- `结构质量 30`
- `形态匹配 25`
- `板块主线 20`
- `可交易性 15`
- `风险洁净度 10`

每只观察池股票必须输出：

- `style_tag`
- `overnight_score`
- `selected_reason`
- `invalidations`
- `10:00_focus`

## 10:00 Confirmation Model

### 1. 输入来源

第一阶段正式推荐 `只能` 从前一晚观察池中产生。

不允许在 `09:30` 以后临时新增陌生股票进入正式推荐。

### 2. 硬过滤

出现以下任一情况直接淘汰：

- 不在前一晚观察池
- `10:00` 时涨幅 `> +4%`
- 前 30 分钟明显冲高回落并破坏关键结构
- 明显弱于所属板块
- 流动性、点差、可成交性异常
- 命中隔夜 `invalidations`
- 风险公告或异常波动导致无法正常执行

### 3. 综合打分

`10:00` 采用 `100` 分制综合打分：

- `个股强度 50`
- `板块共振 30`
- `资金情绪 20`

分项定义：

- 个股强度
  - 价格位置
  - 前 30 分钟结构
  - VWAP 关系
  - 量价质量
  - 隔夜逻辑延续
- 板块共振
  - 板块强度
  - 同伴扩散
  - 核心锚点稳定性
- 资金情绪
  - 主动承接
  - 短线情绪背景
  - 资金稳定性

### 4. 双门槛

正式推荐必须同时满足：

- `总分 >= 72`
- `个股强度 >= 32`
- `板块共振 >= 15` 或 `资金情绪 >= 10`

### 5. 风格差异

在同一评分框架下保留风格差异：

- `A 类`
  更看重回踩后能否重新站稳 `VWAP`、低点抬高、结构修复
- `B 类`
  更看重强势是否稳定延续，同时更严格防范追高和量能失真

## Recommendation Card Contract

每只正式推荐必须生成结构化推荐卡，至少包含：

- `symbol`
- `name`
- `trade_date`
- `style_tag`
- `market_state`
- `entry_time`
- `entry_price_ref`
- `overnight_reason`
- `confirmation_reason`
- `score_breakdown`
- `risk_controls`
- `invalidations`
- `position_plan`
- `confidence_label`

推荐卡文案必须清楚表达：

- 今晚为什么进入观察池
- 今天为什么升级为正式推荐
- 什么情况下代表判断错误
- 系统准备如何退出

## Review & Replay Contract

### 1. 正式推荐状态

观察池与正式推荐结果都必须可追踪状态：

- `promoted`
- `rejected_by_hard_filter`
- `failed_score_gate`
- `weaker_than_alternative`

### 2. 用户轻复盘

用户侧至少要能看到：

- 最近 `20` 笔正式推荐结果
- 胜率
- 平均收益
- 最大回撤
- 正常市 / 弱市表现差异
- 每笔推荐的入选理由、失效条件、退出原因

### 3. 内部深复盘

内部评估面板至少跟踪：

- 交易结果
  - 胜率
  - 单笔平均收益 / 平均亏损
  - 盈亏比
  - 最大回撤
- 执行纪律
  - 止损触发率
  - 硬止损占比
  - 结构止损占比
  - `T+2` 默认退出占比
- 模型质量
  - 观察池转正式推荐率
  - A 类 / B 类胜率和收益
  - 各评分分项与失败率的关系
- 信任经营
  - 连续盈利周数
  - 连续亏损周数
  - 高频失败类型
  - 弱市降档后的效果差异

## Implementation Boundary

第一阶段明确不做：

- 创业板 / 全市场扩展
- 盘中动态止盈
- 临盘新增候选
- 涨停接力主策略化
- 复杂机器学习择时器
- 高频盘口特征深度建模

第一阶段优先做：

- 明确且一致的交易合同
- 观察池与正式推荐分层
- `10:00` 确认机制
- 组合止损
- 正式推荐卡
- 复盘与整改闭环
