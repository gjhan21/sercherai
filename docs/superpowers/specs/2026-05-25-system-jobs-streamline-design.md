# 系统任务中心轻量重组设计

## 目标
- 将 `/system-jobs` 收敛成“任务运行中心”
- 主视图只保留 `总览`、`同步任务`、`运行记录`
- 删除主视图中的配置型与说明型噪音，保留真实高频操作

## 范围
- 前端仅调整 `admin` 侧信息架构与可见模块
- 不新增路由，不重做后端接口
- 不删除底层能力，只从主视图移除 `任务配置` 与 `手动触发`

## 具体调整

### Tab
- 保留：
  - `总览`
  - `同步任务`
  - `运行记录`
- 移除主视图：
  - `任务配置`
  - `手动触发`

### 总览
- 保留：
  - 顶部 hero
  - 核心 KPI 卡
  - 失败原因聚合
- 删除：
  - 动作卡
  - 按任务维度的重试恢复统计
  - 按任务失败原因
  - 右侧使用说明

### 同步任务
- 保留：
  - 新建同步任务
  - 同步任务列表
  - 最近同步快照
- 删除：
  - 顶部同步概览卡
  - 当前窗口提示
  - 右侧使用说明

### 运行记录
- 保留：
  - 筛选
  - 列表
  - 详情
  - 重跑
- 仅做轻度瘦身，不改核心行为

## 验证
- admin 侧单测更新到 3 tab 模型
- 锁定 `config/trigger` 主 tab 不再出现在视图
- 运行相关 `node --test`
- `cd admin && npm run build`
